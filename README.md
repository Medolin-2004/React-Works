# React-Works

A collection of React.js practice projects created while learning React fundamentals. This repository contains examples covering React components, props, state management, hooks, forms, conditional rendering, and more.

## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Node.js
- npm

## Projects Included

| Project | Description |
|----------|-------------|
| Array | Array methods in React |
| Checkbox | Working with checkboxes |
| Component Creation | Creating reusable React components |
| Conditional Rendering | Rendering UI based on conditions |
| Controlled Components | React controlled forms |
| Counter App | Increment & decrement counter |
| CSS Types | Different ways to style React components |
| Expression | Using JavaScript expressions in JSX |
| Map Function | Rendering lists using map() |
| Multiple Inputs | Handling multiple form inputs |
| Login Page | Simple login form UI |
| Toggle Button | Toggle state using React Hooks |
| Props | Passing data between components |
| Random Number | Generate random numbers |
| useContext | State sharing with Context API |
| useEffect | Side effects using useEffect Hook |
| useState | State management using useState Hook |
| Variable | Using variables in JSX |

## Installation

Clone the repository

```bash
git clone https://github.com/your-username/react-practice.git
```

Go to any project

```bash
cd counterapp
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

The application will run at

```
http://localhost:3000
```
